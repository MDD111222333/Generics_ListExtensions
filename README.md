# C_Sharp_Generics_ListExtensions

## C#_Generics_ListExtensions

### Задание «Контрольная точка №30 — модификация обобщённых методов»

Вариант 1. Расширения для списка
1. Статический класс с методом расширения `void Swap<T>(this List<T> list, int i, int j)`, меняющим местами два элемента по индексу.
2. Метод расширения `bool IsEmpty<T>(this List<T> list)`, проверяющий, что коллекция не содержит элементов.
3. Продемонстрируйте оба метода на `List<int>`.
4. Продемонстрируйте оба метода на `List<string>` (или коллекции вашего собственного типа), без единого изменения кода самих методов.
5. Продемонстрируйте `IsEmpty` на пустой, и на заполненной коллекции.
